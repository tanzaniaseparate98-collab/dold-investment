# 🎯 DOLD INVESTMENT

**Professional Digital Business Platform for Freelancing, Online Jobs, and Business Services**

## Project Overview

DOLD INVESTMENT is a secure, mobile-first digital platform that enables:
- ✅ Freelancing and online job marketplace
- ✅ Digital business services
- ✅ Secure wallet and transaction management
- ✅ Referral rewards system
- ✅ Employee management and payroll
- ✅ Financial reports and analytics
- ✅ Complete Swahili and English support

**Target Audience:** Tanzania and international users  
**Platform Type:** Web + Mobile (Android-compatible)

## 📱 Testing on Android Phone

### Option 1: Using GitHub Pages (Easiest)
1. Push your code to GitHub
2. Go to repository Settings → Pages
3. Enable GitHub Pages on the `main` branch
4. Open the deployed URL on your Android phone

### Option 2: Using a Local Server
1. Download VS Code on your computer
2. Install the "Live Server" extension
3. Right-click on `index.html` → "Open with Live Server"
4. Share the local IP address to your Android phone

### Option 3: Android Phone Development
- Use apps like **Termux** or **Pydroid 3** to run a Python server
- Or use **Mozilla Firefox Developer Edition** for debugging

## ⚠️ Important Legal & Financial Notes

### Investment Module (DISABLED)
- The investment feature is currently disabled
- Investment-related functions will only be enabled after:
  - Legal review and approval
  - Compliance verification
  - Regulatory clearance for target countries
  - Proper disclosures and risk statements
- No guaranteed profits will be promised
- User deposits will never be used to pay earlier users
- All investment earnings must come from verified sources

### Payment Processing
- Real money payments are disabled during development
- All transactions are in TEST mode
- Clearly labeled as TEST in the interface
- Production payment integration requires merchant account verification

### User Data Protection
- All passwords are securely hashed
- Personal data is encrypted
- No sensitive information in source code
- Compliance with data protection regulations
